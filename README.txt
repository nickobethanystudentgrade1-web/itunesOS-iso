iTunes System UI 1.0–19.2 — Cross-platform theme starter
===============================================================

This package provides a non-root theme/icon installer framework for Android,
macOS, and Windows 11. It does NOT replace protected operating-system files,
disable security, or install Apple's proprietary system components.

The included "iTunes" UI is a custom theme concept inspired by a music-library
interface, not an official Apple/iTunes system package.

Versions:
  1.0 through 19.2 are represented by the same compatible asset set.
  The version label is a theme target range, not an Apple software version.

Files:
  android/install_android.sh
  macOS/install_macos.command
  windows11/install_windows11.ps1
  windows11/install_windows11.bat

Run only scripts you understand. Windows may require PowerShell execution
permission, and macOS may require Terminal permission to run a .command file.
